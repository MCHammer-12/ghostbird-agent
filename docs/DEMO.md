# Demo plan

## Goal

Show the lift created by client-specific evidence and voice while keeping the base model and task constant.

## Four screenshots

1. **Post enrichment without Ghostbird context** - Give a general model a partial post and no client evidence.
2. **Post enrichment with Ghostbird context** - Use the same model and draft with retrieved metrics, quotes, anecdotes, voice observations, and source references.
3. **Post ideation without Ghostbird context** - Ask the general model for ideas using only a client name and industry.
4. **Post ideation with Ghostbird context** - Use the same request plus Ghostbird's client evidence and voice profile.

## Controlled comparison

Keep these variables identical between each pair:

- Base model and settings
- User request
- Starting draft or ideation goal
- Client
- Requested output length

The only meaningful difference should be access to Ghostbird context.

## Recommended synthetic client

Use Marisol Vance because her synthetic sources contain several clear evidence types:

- Approximately 40% year-over-year revenue growth
- Winning Meridian Air Systems after its incumbent missed two ship dates
- The incumbent relationship had lasted nine years
- The "put your dad on the phone" story
- A new employee's approximately $4,000 first sale
- A half-marathon story and requested visual asset

The generic outputs should remain plausible but broad. The Ghostbird outputs should be recognizably about Marisol, cite their evidence, and sound consistent with her natural speech.

## Presentation

Present each pair side by side. Visually highlight:

- Specific facts and numbers
- Client-specific stories and quotes
- Voice differences
- Source references
- Stronger and more varied post angles

Do not claim that the comparison proves one model is better. The demonstration proves the value of structured client context, retrieval, and voice guidance.

## Success signal

An observer should be able to identify the Ghostbird result without seeing the label because it is more specific, more grounded, and more recognizably tied to the client.
